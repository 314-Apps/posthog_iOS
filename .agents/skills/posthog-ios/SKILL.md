# Working in products/ios

`products/ios/` is the native Swift/SwiftUI PostHog client, an **app-only product**: no Django
backend, no frontend/ scene, no Node toolchain. It is excluded from the root pnpm workspace,
oxfmt (JSON/xcstrings), the Docker build context, and the frontend/backend/storybook CI matrices.

**Read [`products/ios/AGENTS.md`](../../../products/ios/AGENTS.md) before writing code in this
tree.** It is the source of truth for the package layering, API surface rules, auth rules, and
commands. This skill only covers the scoping contract around it.

## Scope contract

Default: **everything you read, edit, run and test lives under `products/ios/`.** Run all
commands with that as cwd (`make generate / build / test / lint`). Do not go fishing in
`frontend/`, `posthog/`, or other `products/*` for patterns — this tree is Swift, and copying
web or Django idioms in is a defect. The one sanctioned read-only reference outside the tree is
`products/desktop/apps/mobile/src/features/auth/` (the OAuth flow this app's auth ports).

Step outside only when one of these is true:

1. **The user explicitly tells you to.**
2. **A backend API the app calls needs to change.** That is a monorepo-side change in its own
   PR — invoke `/improving-drf-endpoints` and `/django-migrations` as usual. The app-side
   contract then updates via `openapi/endpoint-allowlist.json` + `make api-lock`.
3. **iOS CI / config that lives at the root by design.** The list is fixed:
   `.github/workflows/ios-*.yml`, the `ios:*` command entries in `hogli.yaml`, and the
   exclusion entries in `pnpm-workspace.yaml`, `.dockerignore`, `.oxfmtrc.json`, and the
   `changes` filters of `ci-frontend.yml`, `ci-backend.yml`, `ci-storybook.yml`,
   `.depot/workflows/ci-backend.yml`.

## Toolchain (overrides root CLAUDE.md)

| Root says | This tree uses |
| --- | --- |
| ruff / oxlint / oxfmt | SwiftLint + `swift format` (`make lint`) |
| pytest / Jest / `hogli test` | swift-testing + XCTest via `xcodebuild test` (`make test`) |
| kea + LemonUI | SwiftUI + `PostHogDesignSystem` |
| `hogli product:bootstrap` layout | hand-rolled app-only layout (this is the precedent) |

The `.xcodeproj` is generated by XcodeGen from `project.yml` and gitignored — never edit or
commit it; edit `project.yml` and run `make generate`.

## Hard rules worth repeating

- `/api/projects/{id}/…` only; `/api/environments/` is deprecated and CI-blocked
  (`scripts/check-api-drift.py`).
- OAuth redirect scheme is `posthog-ios://oauth/callback`; never reuse the RN app's `posthog://`.
- Never let anything here touch the root pnpm lockfile, pyproject, or Django settings.
